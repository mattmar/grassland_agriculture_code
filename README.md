# Nitrogen inputs and land use shape spatial patterns of grassland plant diversity across Europe

This repository contains the R code used for the statistical analyses and figures presented in:

**“Surrounding low-intensity agriculture benefits grassland plant diversity across Europe”**

The analysis uses spatial Bayesian models fitted with Integrated Nested Laplace Approximation (INLA). Spatial dependence is represented using a barrier stochastic partial differential equation (barrier-SPDE), allowing the effects of nitrogen inputs, land use, climate, edaphic conditions, survey characteristics, and spatial structure on grassland plant diversity to be quantified across Europe.


## Workflow

The scripts are organised according to the main stages of the analysis.

### 01 — Data preparation and screening

`01_inla_model-part01.R`

This script:

- loads vegetation-plot data and associated environmental covariates;
- harmonises survey years and land-use classes;
- applies the data transformations and exclusions used in the analysis;
- constructs a spatial mesh and barrier-SPDE model;
- fits a preliminary Gamma INLA model excluding nitrogen predictors;
- calculates conditional predictive ordinate (CPO) and probability integral transform (PIT) diagnostics;
- applies the diagnostic, nitrogen-budget, and arable-land screening criteria used in the analysis;
- saves the filtered dataset used by the main model.

Output:

```text
data/evaVS_formodel.RDS
```

### 02 — Main spatial INLA model

`02_inla_model-part02.R`

This script fits the main model used for the results reported in the manuscript.

The response variable is grassland plant diversity, modelled using a Gamma likelihood with a log link.

The model includes fixed effects for:

- nitrogen fertiliser input (`NBud`);
- atmospheric nitrogen deposition (`NDep`).

Additional terms account for:

- Corine Land Cover level-2 class grouping;
- biogeographical region;
- survey year;
- vegetation-plot area;
- soil pH;
- temperature;
- precipitation;
- elevation;
- spatial autocorrelation.

Spatial dependence is represented by a barrier-SPDE model.

The script also back-transforms the nitrogen coefficients to the original predictor scale and saves the fitted model used by subsequent scripts.

### 03 — Main figures

`03_figures-part01.R`

This script produces the main model-based figures used in the manuscript, including:

- observed relationships between diversity and nitrogen inputs;
- modelled responses to nitrogen fertilisation and atmospheric nitrogen deposition;
- land-use effects;
- spatial predictions and maps;
- selected species-level responses.

The script uses the fitted model and processed data generated by the modelling workflow.

### 04 — Additional model visualisations

`04_figures-part02.R`

This script produces additional visualisations of posterior model effects, including effects associated with:

- biogeographical region;
- survey year;
- vegetation-plot area;
- soil pH;
- temperature;
- precipitation;
- elevation.

Posterior effects are transformed to the response scale where appropriate.

### 05 — Individual predictor contribution

`05_inla_model-absolute-contribution.R`

This script evaluates the support associated with individual model components.

Each predictor is fitted separately against an intercept-only baseline while retaining the same response distribution and model parameterisation used in the main analysis.

Individual predictor support is evaluated primarily using differences in log marginal likelihood relative to the intercept-only model.

These values describe the information provided by each predictor when considered individually and should not be interpreted as an additive partition of explained variance.

### 06 — Sequential predictor contribution

`06_inla_model-marginal-contribution.R`

This script evaluates the additional contribution of predictors as they are added sequentially to the model.

For each step, model support and fit are compared with the preceding model using quantities including:

- log marginal likelihood;
- deviance information criterion (DIC);
- conditional predictive ordinate (CPO);
- Bayesian R².

The resulting contribution of each predictor is conditional on the variables already included in the preceding model and is therefore dependent on the specified order of model construction.

The script also records changes in the estimated nitrogen coefficients as additional model components are introduced.

## Data

The vegetation-plot data used in the study originate from the **European Vegetation Archive (EVA)**.

The specific EVA data selection used in the study is identified by:

**DOI:** https://doi.org/10.58060/jeht-nr04

EVA vegetation-plot data are subject to the data-use conditions of EVA and the contributing vegetation databases and are therefore not redistributed in this repository.

Environmental and spatial covariates used in the analysis are described in the manuscript and its Methods and Data Availability sections.

Users wishing to reproduce the complete workflow must obtain the corresponding source datasets and place the required input files in the locations expected by the scripts.

## Software requirements

The analysis was performed in R.

Recommended minimum version:

```text
R >= 4.3
```

Packages used for individual figures or data-processing steps are loaded within the corresponding scripts.

INLA is distributed through the R-INLA repository rather than CRAN. Installation instructions are available from the R-INLA project.

## Running the analysis

The modelling workflow should be run in numerical order:

```text
01_inla_model-part01.R
02_inla_model-part02.R
03_figures-part01.R
04_figures-part02.R
05_inla_model-absolute-contribution.R
06_inla_model-marginal-contribution.R
```

Scripts 01 and 02 constitute the core modelling workflow.

Scripts 03 and 04 reproduce manuscript figures from the fitted model and associated outputs.

Scripts 05 and 06 reproduce the individual and sequential model-contribution analyses.

The scripts assume that the repository directory structure is retained and that required input datasets are available locally.

## Reproducibility

Random seeds used for mesh subsampling and other stochastic steps are set explicitly within the scripts.

Model specifications, prior distributions, spatial mesh settings, and INLA control parameters are defined directly in the corresponding scripts.

Because INLA and supporting spatial libraries continue to evolve, small numerical differences may occur when analyses are run with software versions substantially different from those used for the published analysis.
